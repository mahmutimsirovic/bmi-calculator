# BMI Calculator

A simple web app that calculates Body Mass Index (BMI) based on user input for height and weight.  
Built with **HTML, CSS, and JavaScript**.

## ✨ Features
- Input height (cm) and weight (kg)
- Calculates BMI with one click
- Displays BMI value and category (Underweight, Normal, Overweight, Obese)
- Responsive design with gradient background
